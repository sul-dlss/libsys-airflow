{# DAG run progress indicators. Polls endpoint (a JSON {"runs": [...]} built from shared.dag_runs.active_dag_runs, with each run's "progress_keys" added) while runs are queued/running, and shows a progress bar in each matching row. Tag rows with data-progress-key="" and the cell that shows the bar with data-progress-cell. Inside that cell, an element with data-progress-status="" has its text replaced with while a run is active (e.g. "Unknown" -> "In progress"). Once a tracked run finishes, the page reloads so the tables pick up the new state. (See for example: libsys_airflow/plugins/google_scanning/templates/google_scanning_upload/index.html) labels maps dag_id to the text shown next to the bar; unlisted DAGs show their dag_id. #} {% macro dag_run_progress(labels={}, endpoint="progress") %} {% endmacro %}
